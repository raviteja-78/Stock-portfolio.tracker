CodeAlpha Task 2: Stock Portfolio Tracker

Project Overview

The Stock Portfolio Tracker is a simple Python application that calculates the total investment value of stocks based on user-entered stock names and quantities.

Features

Accepts stock names from the user.
Accepts the quantity of each stock.
Uses predefined stock prices stored in a Python dictionary.
Calculates the total investment value.
Displays the investment summary.
Can optionally save the result to a text or CSV file.
Technologies Used

Python
Dictionary
User input and output
Basic arithmetic
File handling (optional)
How It Works

The program asks the user to enter a stock name.
The user enters the number of shares.
The program looks up the stock price from a predefined dictionary.
It calculates the investment value by multiplying the stock price by the quantity.
It displays the total investment value.
Example

If the stock price is ₹180 and the quantity is 5 shares:

Total Investment = 180 × 5 = ₹900

This is an illustrative example, not a live market price.

How to Run

Install Python.
Open the project folder in VS Code.
Run the Python file:
python stock_tracker.py

Replace "stock_tracker.py" with your actual Python filename if it is different.
